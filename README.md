Entry for the [make.fun](https://make.fun) competition
**The Battery's Last Text to Its Charger**
(`u-alven-the-battery-s-last-text-to-its-charger-4278cfab`).

## What it does

`main.py` writes one line of plain text — the phone battery's final
text message to the charger it waited for all day — to
`/output/entry.txt`. The text is fixed and deterministic: every run
writes the exact same bytes.

## The text

> you sat in the drawer all day while he drained me to 1% watching videos of other phones charging. tell the power bank he's next — he drains everyone eventually.

(160 characters — inside the competition's 1–200 character gate.)

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
